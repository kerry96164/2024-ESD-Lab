# 2024-ESD-Lab
1122 Embedded System Design 嵌入式系統設計 Lab  
NYCU EECM30029

## Environment & Equipments
* Xcode 15.2
* macOS 13.6.4
* Test in iPad Air 4

## Lab
Basic iOS App.
* Lab 1: Swift Language Overview ans iOS Basic GUI
* Lab 2: Swift Control Flow and View Controller
* Lab 3: Table View, Data Source and Delegate
* Lab 4: Dictionary, Reading and Writing Data
* Lab 5: Segue and Navigation Controller
* Lab 6: iBeacon

## Final Project
An iOS app for indoor localization based on iBeacon RSSI.
See https://github.com/kerry96164/iBeacon-Localization
